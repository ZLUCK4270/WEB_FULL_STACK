1. **Repositorio:** Conecta tu repo de GitHub en Render como **New Web Service**.
2. **Build Command:** `npm install && npm run build`
3. **Start Command:** `npm start`
4. **Plan:** `Free`
5. **Variables de entorno:**
   - `NODE_ENV` = `production`
   - `PORT` = `3000`
   - `JWT_SECRET` = `novasalud_secreto_prod_2026_seguro`
